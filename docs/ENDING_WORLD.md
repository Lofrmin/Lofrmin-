# 结尾：环的另一面

本版为 90 秒 AIGC 画面与原创动态图形合成的结尾动画，配乐为用户提供的《阿鲲 - 前行》。按用户选择，将原长 3:16.64 的音乐精剪为 90 秒，选取 1:46.64–3:16.64，立体声混音，开头 2 秒淡入、尾端 1.5 秒平滑收尾，保留自然强奏和余音。无配音。视频与配乐同长；镜头重新安排，不是将原 64 秒成片整体慢放。结尾的目的为揭晓当前故事的结果，让玩家重新理解既有线索，并提供从第一章重走的入口。

## 这次揭晓的结果

1. **账本已出站。** E-7 把完整账本送到独立审计节点。站内复位无法撤回站外存证。
2. **管理层失去清算权。** 受益账户被冻结，A-42 后续扣款终止，授权签署记录进入追责程序。没有用一句“全部惩处”跳过尚未发生的审理过程。
3. **林岑存活。** 玩家选择不再次签字，并把记录送出，阻止了后续清算。历史交易不会因复位回滚，已经失去的寿命没有凭空归还；救下的是他剩余的时间。
4. **空间站依然成环。** 事故造成的莫比乌斯结构和晨暮时差属于物理损伤，撤销账户授权不会顺带修复空间裂隙。动画里的环带为世界观表达，不将千倍时差宣称为现实拓扑学结论。
5. **遗书来自玩家。** 沿用 `inspect_office()` 中本已有的“遗书是你的笔迹”，在片尾明确其为留给下一轮自己的警告。故事没有新增另一位幕后角色来替换既有线索。

## 游戏接入与协作边界

- 只在 `upload` 完成、`cleared` 存档成功后调用 `begin_epilogue()`。合并版保留队友的 30 秒终局追逐，抓获会中止传输，成功后先清理敌人、同步中继状态，再进入电影。
- 播片时冻结游戏模拟、停止游戏音效；结束或跳过后打开回执页。缺失视频则直接显示回执，不阻塞通关。
- 开场与结尾均进入 `CorrAmbience` 音频总线，受现有总音量与氛围音量设置控制；播放器以 -8dB 抵消该总线默认的 +8dB 增益，保持成片原有响度。
- 回执可重看动画、保存退出或开始回声调查。回声调查重置五章的进度，从晨区 A-01 开始，跳过已看过的开场电影。叙事上是审计匣重建已经归档的调查，而不是冻结账户后再次发生新扣款，避免让结尾的解救失效。
- `echo_run` 是可选存档字段，保留“已知遗书意义”的叙事状态；旧存档默认 false。服务端保存整个 state 字典，已有校验兼容这个字段，不需改后端接口。
- 回声调查的题目与答案沿用当前五章；改变开场提示和 B-17 遗书的指代。没有承诺未实现的隐藏关卡或第二套结局。
- 明确点击“重新开始调查”仍会清除章节、证据和回声状态，并播放开场电影。
- 已通关的旧存档继续后到回执页，可手动选择“重看结尾动画”。
