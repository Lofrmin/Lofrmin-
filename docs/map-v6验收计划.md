# Panda Jam 地图 v6 验收计划（待实机联调）

> 状态：文档/测试计划；不代表全地图实机或性能验收已经完成。

## 进度阶段和真相顺序

- 游戏内部章节索引并非故事顺序：`0 → 3 → 1 → 4 → 2`，断点阶段映射 `S1 → S2 → S3 → S4 → S5`。
- 确认 `station.STORY_STEP` / `game.STORY_ORDER` 与 `NEXT_CHAPTER` 一致；新调查回到 S1，继续游戏按存档回到相应阶段。
- 章节推进以进入/返回 A-01、复位、异步存档回调等实际路径为准；若地图阶段在玩家身边变化，确认不会把玩家封进墙中。

## 地图拓扑、动态封闭和交互点

- 两种时态与 S1–S5：A-01、B-17、C-04、D-09、L-06、R-03、GUARD 与四个 G 门可达；路径不经过封闭格，四方向移动连续。
- S2–S4 每组断点：`walkable`、A* solid、墙显隐、静态碰撞状态一致；重新跨章节阶段时该组正确打开/关闭。
- `return_hint` 箭头落在可走格并沿真实 A* 最短路径指向最近可用出口；危险大地图持续标出追债位置/警告。
- 玩家实际运行：随机走至断点将要关闭的区域再推进阶段、进出四门、靠墙移动；不陷入碰撞，不穿墙或卡门。

## 单体追逐与复位

- 每轮首次进暮区生成一名追债人；在晨区保持隐藏、冻结。返回暮区时位置不重置，同一轮脉冲次数不回充。
- 全局只有一个追债实例；跨相门追踪的下一目标是玩家最近实际使用的门。核对路网变化后双方均可绕障。
- 一轮仅第一次换相取得 2 秒门口保护；重复往返不刷新保护。开新轮/死亡复位才按规则重置追逐状态。
- 终局：从晨区 A-01 发送时开始 6 秒倒数，追债人从最近安全晨区 G 门出现；大地图始终显示正确的危险标记。验证取消/死亡/完成边界。

## C-04 新交互回归

- 章节 02 仍保留谜底：用暮区 5000 / 1000 得出晨区 5 秒，扣款（debit）早于立案（filing）。

- 存档、复位以及章节真实跳转顺序不变，不允许旧的单步选择捷径推进。
