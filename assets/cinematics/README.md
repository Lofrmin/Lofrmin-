# 开场与结尾动画

`prologue.ogv` 是游戏运行所需的 72 秒世界观先导片，1920×1080、24 fps，Theora 视频 / 48 kHz Vorbis 立体声。由用户审阅的配乐版转码，使用用户提供的《阿鲲 - 开场 介绍数字生命》开头 72 秒，含淡入淡出及低音量原创电子氛围声。

画面采用 AIGC 概念美术、镜头运动、原创拓扑动态图形和中文字幕。剧情顺序为空间事故、环带撕裂并半周扭转后闭合成莫比乌斯环、晨暮时区和千倍时差，最后衔接林岑失联与 B-17 调查。

`prologue.gd` 负责等比播放和跳过。新调查先播片，结束或使用 Space / Esc / 跳过按钮后进入原有引导；继续旧存档和轮回复位不重播。视频缺失时直接进入引导。

本地制作目录 `prologue-v1/` 包含原始概念画面、提示词、渲染脚本、原始音乐和中间文件，由 Git 和 Godot 忽略；运行游戏只需要本目录的 `prologue.ogv`。

## 结尾：环的另一面

`epilogue.ogv` 为 90 秒结尾，1080p / 24 fps / Theora / Vorbis。通关存档写入后自动播放，结束或跳过后进入回执页；旧通关存档可在回执页重看。配乐改为用户提供的《阿鲲 - 前行》，选用 1:46.64–3:16.64 的完整 90 秒段落，镜头时长重新分配，保留强奏与自然尾音。

结尾交代林岑存活、历史交易保留、受益账户冻结与后续扣款终止，以及空间站的莫比乌斯结构仍然存在。最后揭示 B-17 遗书来自玩家自己，并返回开场构图。完整叙事与协作接口见 `docs/ENDING_WORLD.md`。

“带着真相再走一圈”会开始回声调查，从第 01 章重建归档记录，保存可选字段 `echo_run`，并在开场与 B-17 对应结尾提供呼应文案。原有谜题流程保留。

本地制作目录为 `ending-v1/`（被 Git 与 Godot 忽略）；复现脚本位于 `tools/cinematics/build_epilogue.py`，媒体验证位于 `tools/cinematics/verify_epilogue.py`。运行包只需要 `epilogue.ogv` 和 `assets/ui/ending_cover.png`，不依赖制作脚本或原始音轨。
