# 开场先导片

`prologue.ogv` 是游戏运行所需的 72 秒世界观先导片，1920×1080、24 fps，Theora 视频 / 48 kHz Vorbis 立体声。由用户审阅的配乐版转码，使用用户提供的《阿鲲 - 开场 介绍数字生命》开头 72 秒，含淡入淡出及低音量原创电子氛围声。

画面采用 AIGC 概念美术、镜头运动、原创拓扑动态图形和中文字幕。剧情顺序为空间事故、环带撕裂并半周扭转后闭合成莫比乌斯环、晨暮时区和千倍时差，最后衔接林岑失联与 B-17 调查。

`prologue.gd` 负责等比播放和跳过。新调查先播片，结束或使用 Space / Esc / 跳过按钮后进入原有引导；继续旧存档和轮回复位不重播。视频缺失时直接进入引导。

本地制作目录 `prologue-v1/` 包含原始概念画面、提示词、渲染脚本、原始音乐和中间文件，由 Git 和 Godot 忽略；运行游戏只需要本目录的 `prologue.ogv`。
