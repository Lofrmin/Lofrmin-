# 逐光计划 · 静默回声

一段求救信号在木星阴影区重复了七天。四个席位负责保护领航员空间站、调查信号源，并在最后一波协同打击母舰。

## 打开游戏

双击 `Start-Game.cmd`。也可以在 Godot 4.7 中导入 `project.godot` 后按 F5。Windows 启动器会在首次运行时导入素材。找不到 Godot 时，可将 GODOT_EXE 环境变量指向其可执行文件。运行 Godot 命令行测试时，可用 GODOT_CONSOLE 指定控制台版 Godot。

待命时游戏呈黑屏，底部显示「挥手唤起操作界面」。按 **C** 并在控制窗口点击「开启摄像头」，授权后切回游戏，张开单手左右挥动再挥回。建议在控制窗口先完成「个人校准」。不使用摄像头时，按 **Enter** 唤醒，再按一次开始作战。**F11** 切换全屏。

## 四席分工

| 席位 | 职责与指令 |
| --- | --- |
| F1 队长 | 统筹三项能源分配（1 / 2 / 3），维修两翼（F），第三波授权发射（J） |
| F2 小医生武器官 | 锁定母舰核心（F），开始或暂停充能（Q），所有闭锁解除后发射（X） |
| F3 游隼编队 | 侦察拦截、超频机动（B），接近母舰后启动测绘（E） |
| F4 玄武编队 | 护航修复、偏转护盾（B），接近母舰后压制屏障（E） |

单机可用 **F1–F4** 随时换席，各席已经下达的任务会继续执行。无人机席拖拽编队绘制航路，点选敌舰指派攻击，右键快速部署，W / S 升降。滚轮缩放，中键拖动旋转。单机可按空格或张掌进入战术慢速。队长按 Esc 暂停，R 重新部署。

手势模式下，单手捏合可点击按钮或抓取编队，拖动手掌、松开确认。双手张开可调整视野。小医生席可以用双手同时捏合约 0.7 秒确认发射，仍需满足所有闭锁条件。

## 四人联机

四台电脑连接同一局域网。各自打开项目并唤醒操作台，按 **L**。队长点击「创建房间」，其余三人输入队长界面显示的局域网 IPv4 地址并加入。游戏会分配未占用的席位。四席到齐后由队长开始作战。房主使用 UDP 19754，各台电脑的摄像头在本机处理。

## 最后一波

1. 队长切到武器供能，武器官启动充能。
2. 游隼与玄武分别进入母舰 42 km 内，启动核心测绘和屏障压制。
3. 武器官锁定母舰，队长签发授权。武器官在面板四项闭锁解除、充能达 100% 后发射。
4. 小医生摧毁母舰及其附近敌军。清除剩余敌舰后完成任务。

## 验证

- Godot `--headless --path . -- --self-test` 验证黑屏唤醒、权限、航路、射程门槛、小医生闭锁和任务结局。
- `node tools/test-four-seat-lan.mjs` 启动四个实例验证席位分配和房主状态同步。
- `node tools/test-gestures.mjs`、`node tools/test-camera.mjs`、`node tools/test-native-bridge.mjs` 与 `node tools/test-browser.mjs` 验证合成挥手、手势稳定层、本机桥接及模拟视频。
- Godot `--path . -- --capture` 保存待命和四席实机图。

地球纹理来自 [Three.js 示例](https://threejs.org/examples/textures/planets/)。手势使用 [Google MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。摄像头画面在本机处理，游戏接收手势事件。
