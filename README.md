# 回廊：借来的明天

Godot 4 原型。你在双时态空间站里收集记录、比对证据，躲过追债人的清算。

## 运行

Windows 上安装 Godot 4 和 Python 3 后，双击 `Play.cmd`。启动器会在首次运行时导入贴图，并启动本机 Python 存档服务。它通过桌面的 `Godot.lnk` 或系统 `PATH` 查找 Godot，也可以将 `GODOT_EXE` 环境变量设为 Godot 可执行文件的绝对路径。

也可以在 Godot 中打开 `project.godot`，按 F5 试玩。直接在编辑器内运行时，如果后端未启动，会使用本地存档。

WASD 移动、鼠标环视、Shift 奔跑、E 交互、F 断相脉冲。M 打开/关闭大地图，Tab 切换晨区/暮区地图预览；预览时人物仍留在原时态，必须到地图中的任一 G 门靠近后按 E 才会真正换区。Esc 暂停或返回。操作手册按 H 查看。

第 01 章在证据工作台同时选中门禁 V-17 与警报 #043，再按 Enter 核验；不能再用旧的单项选择直接跳过。地图含四扇换相门、S2–S4 阶段性封闭的断点墙。追债预警可在大地图中查看。答案与剧情解法见《谜题答案.md》。

序幕和舷窗使用参考项目《逐光计划》中的地球和云层贴图。参考项目将纹理来源标注为 [Three.js 示例](https://threejs.org/examples/textures/planets/)。

带着暮区的关键证据回到调查台，才能写入审计匣。轮回次数、章节、已保存的证据和通关状态保存在本机，联网到本机服务时同步到 `backend/data/players.sqlite3`。

## 配置 DeepSeek

在项目目录打开 PowerShell，运行下面的命令，然后在隐藏输入提示中填入新密钥。密钥使用 Windows 当前账户加密保存，之后双击 `Play.cmd` 即可。

```powershell
.\Play.cmd -ConfigureDeepSeek
```

后端在追逐后的复位阶段请求 `deepseek-flash`，仅发送追债人的门禁观测次数和奔跑听觉标记。模型返回预设战术和换相门编号。未配置密钥或调用失败时由本地规则接管。HUD 出现 `追债策略 / DeepSeek` 表示本轮已采用模型结果。

- 追债人：进入暮区部署一名巡逻；首次进入有 2 秒免伤缓冲，不恢复脉冲。暮区提交新证据或接线后触发 12 秒封门追逐。主追债人从身体无碰撞、可达且距玩家至少 28 米的安全点随机部署，尽量避免重复。设置默认 1 名，可选总计 2/3 名；仅下一轮生效，安全点不足时不强行刷怪。

- 回晨区清除所有追债人、路线、光栅与危险 HUD；再次进入暮区重新部署单名巡逻。死亡、重开、换章、开发者定位也清空额外池。暂停同步停止全员动画与声音。终局晨区 A-01 上传仍持续 6 秒，全程安全，上传期间不能换区。
- 柱体采用连续深灰结构、端部封套及内嵌细纵条；晨区蓝色、暮区橙色，待机均不自发光。只有当前光栅两端的灯条在预警时亮橙、运行时亮红，光栅撤回后恢复待机。
- 动态光栅的 0.85 秒预警暂不阻挡，运行时只挡玩家；追债人的移动、视线和寻路均可穿过光栅，真实墙体和设施仍会阻挡追债人。光栅保留逃路及全员 10 米危险区保护，每 0.2 秒复查，不安全时提前撤回。
- 开发者按键只供编辑器/Debug 调试；Windows Release 导出中禁用。
- 追债人无遮挡时追玩家的实际坐标，不再只追到 4 米网格中心；有墙时保留 A*，桌边用邻格绕行。移动使用身体胶囊扫掠，近身结算也要求通路无遮挡，避免切墙角、穿桌或隔墙抓人。

## 开始界面与第一轮引导

启动后停在开始界面，不会自动进入游戏。有已归档进度时按 Enter 继续；按 N 开新调查，必须确认后才清除旧进度。继续调查会回到晨区 A-01，不是恢复上次站立位置。

新调查会先播放 72 秒的配乐先导片，介绍空间事故、莫比乌斯环与晨暮千倍时差。播放结束、按 Space / Esc 或点击右下角“跳过先导片”后，进入原有三页引导；引导按 Enter 逐条阅读，Space 可直接进入调查。继续旧存档和轮回复位不会重播；从暂停页重新建立新调查会重播。先导片使用 `assets/cinematics/prologue.ogv`（Theora / Vorbis，1080p），配乐为用户提供的《阿鲲 - 开场 介绍数字生命》。

H 查看操作说明；从暂停页打开说明，关闭后仍保持暂停。M 仅切换地图预览，真正换区要在 G 门按 E。HUD 会按当前线索、未归档记录和追逐状态给提示，目标、广播与终端通知支持换行。未加入跳跃，地图/碰撞和资产保持队友版本。

新增回归：tests/menu_test.gd（状态、键盘、存档保护、换行）和 tests/menu_visual_check.gd（1280×720 / 1920×1080 鼠标流程；命令行参数与 visual_check.gd 相同）。

追击氛围音使用原创合成的心跳与打击循环：巡逻时静音，被发现/追踪时按威胁渐强，脱离后渐弱；晨区换相、暂停和轮回复位立即停声。无商业游戏采样。

Shift 满体力可冲刺约四秒；停止冲刺 1.25 秒后可在行走中恢复。耗尽后恢复到 25% 并松开 Shift，才能再次冲刺。换相不补体力，轮回复位回满，F 仍独立使用每轮两次。普通可见追踪速度为 5.2m/s，终局晨区上传仍为六秒，但遵循 v7 晨区安全规则，不再刷追债人。


## 声音与难度设置

开始菜单或暂停页进入“声音与难度”，可调总音量、音效、警报与追逐氛围；总音效与警报总线增加 6dB、追逐氛围增加 8dB；部署/冲刺保留空间音并增加远距警报层，主总线限制峰值至 -1dB。音量即时生效，人数 1/2/3 从下一轮生效；配置存入独立 preferences.cfg，不改调查存档。

人数从菜单开始新调查或下次轮回复位时生效，进入暮区就按该轮人数部署，不再等到取证才生成额外追债人。HUD 不显示敌人距离，保留人数和危险状态；安全位置不足会显示实际部署数。


## 首次多追债人提示与背景音乐

首次实际部署两名及以上追债人时显示教学提示，阅读期间世界暂停；Enter/Space/Esc 或按钮确认后继续。普通轮回不重复提示，新调查重置。

探索与菜单使用主办方平台一次 Suno v6 任务生成的约75秒原创氛围配乐；遇险时压低，暂停/先导片/教学提示期间停止，受追逐氛围音量控制。来源记录见 assets/audio/GENERATED-MUSIC.md。队长先导片原片和原配乐保持不变，新配乐先导片对比版仅存于工程外。
