# 为爱黔行 · 同行工作台（第二版试点）

需要 Node.js 24 或更新版本，无第三方依赖。双击 `启动工作台.cmd`，或在本文件夹运行 `npm start`，浏览器打开 http://localhost:3000 。关闭终端会停止本地服务。

## 首次启动与演示账号

公开源码不包含登录密码。首次启动前，在 PowerShell 中将 `WEIAI_DEMO_PASSWORD` 环境变量设为你自行选择的至少 12 位密码，再运行 `npm start`。此值用于初始化各演示账号；之后数据仍保存在本地数据库中。云端部署也需设置同名运行时环境变量。不要把真实密码提交到仓库。

## 已实现

- 教师照片打卡、课堂内容、人数、时长、素材授权确认；按北京时间每位老师每间教室每天一次；教师间公开浏览并相互鼓励。
- 工作人员最高权限：素材整理、分段图文编辑（正文、小标题、引用、图片）、草稿预览、人工审核发布、撤回。
- 动态关联多个团队，发布后对对应资助人定向展示并发站内通知，已读与查看记录留痕。
- 邀请码创建、角色及团队绑定、7 天有效、一次性兑换、撤销；成员团队关系调整。
- 连续未打卡提醒，周期可设为 1–90 天；跟进记录及给老师发送站内提醒。
- 团队新增、操作日志、服务端权限校验、登录会话、密码 PBKDF2 哈希、受保护的上传图片访问。
- 手机布局与桌面布局。

## 演示方式

1. 用 staff 登录，查看打卡素材，点击“整理图文”，保存草稿，预览后确认人工审核发布。
2. 退出并使用 donor 登录，查看自己关联团队的新动态和消息。
3. 用 donor2 登录，确认不能看见其他团队内容。
4. staff 创建老师或资助人的邀请码，在退出后的登录页选择“收到邀请码？加入团队”。
5. teacher2/teacher3 等老师可上传照片并打卡，工作人员在打卡提醒页设置周期和记录跟进。

## 保存、验证与部署

本地 SQLite 数据在 `data/weiai.sqlite`，上传图片在 `data/media/`。停止服务后备份整个 `data` 文件夹。数据保留到下次启动。`npm test` 运行权限与核心流程测试；`npm run build` 生成 Cloudflare Worker 版本，云端使用 D1 和 R2，与本地数据库独立。

## 首版边界

- 本版为小规模试点，使用单行 JSON 状态存储；云端状态限制约 1.5MB，图片单独存放 R2。规模化前需拆分关系表、分页与完整审计归档。
- 提醒为站内计算：打开页面及每分钟刷新时更新；没有站外定时推送。短信、邮件、飞书、公众号同步和抖音数据导入尚未接入。
- 图文编辑采用可调整内容的分段表单，支持文字与图片，无公众号完整排版能力或直接群发能力。
- 图片移除了下载入口并校验读取权限，但无法阻止浏览器截图或获授权用户提取图片。正式使用前需落实儿童影像授权与脱敏。
- 演示账号用于试用。正式上线前需要独立管理员初始化、更换演示凭据、持久化登录限流、备份与恢复、细化授权和素材保留规则；当前在线预览保持仅所有者可访问。
